## A：阶段路线

- 约0–6.7秒：实拍学习/电脑背景，引导句、时间、主题逐层进入；主题大字从超画幅缩回；随后左右条件与正反图标对照。
- 约6.7–11.6秒：双资料卡预览路线，依次叠时钟、两种人物状态与强调字。
- 约11.6–17秒：深色透视网格正文底板。第一阶段标题先居中，缩小归位左上；两张基础卡进入并停留，旧卡压暗留后，新卡从下方进入前景。
- 约17–23.4秒：第二阶段标题和双卡；右侧流程词依次累积，随后中央关键词叠前景。
- 约23.4–30.6秒：第三阶段标题；圆形裁切焦点转为完整横图，竖向标签逐条展开，再换应用图与用途角色。未确认具体遮罩插件。
- 约30.6–44.5秒：新阶段标题重置注意力，框架资料双卡与角色标签递进，再由项目图标切项目资料卡，最后叠结果短字。
- 约44.5秒后：一主两辅资料窗口固定，主窗口内思维导图沿分支平移浏览，最后短词收尾。

可复用机制：章节标题建立层级；双卡建立概念关系；前后景替换体现递进；标签把密集截图转成可扫读重点。

## B：成果—知识—实战—合集

- 约0–8秒：招聘/结果资料截图叠放，大号红字强调时间、数量或薪资，再切人物插画表达面试情境。仅借用表现方式，不继承数值主张。
- 约8–16秒：人物/实拍/工具标识等画面切换承接“需要什么能力”。
- 约15.7–26.3秒：暗底十字纹，问题短句切步骤胶囊，再切顶部主题条。卡片逐张进入，旧卡横移重排成横列。10fps复查可确认新卡从模糊形变到正面落稳，不能据此确定真实3D翻转、转轴或原生效果。
- 约26–35秒：工具分类大图/多资料卡逐步铺开，新增卡片覆盖局部前景，保留已讲卡片形成知识积累。
- 约35–44秒：电脑实拍与单项目资料交替，说明“学知识”如何落到“做项目”。
- 约44–52秒：左侧大文档窗口，右上目录、右下教程合集。左侧文档内容在固定版式中向上滚动换段，最后叠醒目的短词作为行动提示。开场合集过渡可见卷页状形变，具体效果名称未知。

可复用机制：证据建立兴趣；固定主题下逐张累积；实拍提供节奏呼吸；合集版式保持稳定而局部内容滚动。

## 运动选择速查

| 信息目的 | 推荐方式 | 必须写清 |
|---|---|---|
| 列举知识点 | 新卡进入、已有卡向左重排 | 总张数、每张落点、重排时机 |
| 新知识覆盖旧知识 | 旧卡降低亮度，新卡前置 | 层级、旧卡是否继续可见 |
| 展示长资料 | 固定圆角窗口，图片向上滑 | 裁切窗口、滚动距离、停留重点 |
| 双方案比较 | 两卡并排固定 | 左右含义、强调轮次 |
| 聚焦细节 | 局部裁切/放大与标签 | 放大区域、可读文字、回退方式 |
| 章节变化 | 清场→标题→标题归位→卡片 | 各事件时机，背景是否延续 |
| 结尾资料感 | 主文档+两个辅卡 | 主次比例、滚动内容、收尾字 |

资料卡不等于纯文字矩形：可用知识图解、路线图、工具清单、项目界面、文档截图；优先匹配用户现有素材。表情贴纸、人物、印章字是可选强调层，不是每镜必需。
