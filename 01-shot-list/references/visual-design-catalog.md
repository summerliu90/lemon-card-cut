# 图片选型与全片素材搭配

01规划前读取。本目录解决“为什么为这句话设计这张图”，具体任务书仍按image-design-spec；视频另按video-asset-spec。全片固定字体、颜色语义、卡片系统和角色身份，图型与材质可以变化。图型、表现风格、运动方式分别决策，不能把换色或换动画当素材丰富。

## 按信息关系选图型

| 主图型 / diagram_type | 信息任务 | 软件测试例子 | 设计重点 |
|---|---|---|---|
| 概念解释 / concept | 定义、边界、概念与例子 | 测试用例是什么；断言是什么 | 一个主概念、简短定义、具体对象或例子 |
| 组成拆解 / anatomy | 一个对象有哪些部分 | 示例用例的前置条件、数据、步骤、预期结果 | 真实示例作主体，部件标注独立；不宣称某套字段适用于所有团队 |
| 方法对比 / comparison | 同维度比较多种方法 | 等价类和边界值的用途 | 对齐比较维度、各自实例；不编造优劣结论 |
| 步骤流程 / process | 顺序、判断、回路 | 从需求分析到用例评审 | 明确入口、动作、判断与终点，箭头独立 |
| 实例批注 / annotated-example | 用具体对象解释抽象原则 | 逐项解释一条登录用例 | 示例、批注、选中框分层；明确“示意” |
| 正误对照 / before-after | 同一对象的缺陷与改进 | 含糊预期与可验证预期 | 同一例子和相同维度；问题与改法可一眼对应 |
| 知识结构 / structure | 层级、模块、归属 | 接口测试覆盖维度 | 结构关系不冒充执行顺序；分组可读 |
| 清单与知识地图 / checklist-map | 复核、归纳、全貌 | 用例评审清单 | 条目按当前内容确定；总览与逐项教学分开 |
| 界面与证据 / ui-evidence | 操作、状态、证据 | 运行结果、日志、缺陷详情 | 真截图保留来源；自制界面标示意，重点区域可放大 |
| 情境与隐喻 / scenario | 困惑、协作、结果或转折 | 漏测后的排查、需求评审 | 具体主体、动作、环境；不代替核心技术解释 |

提到“测试用例”不意味着自动扩写一套教程。先判断这句是在定义、解释组成、教方法还是举例，再设计对应图片。补充实例必须注明是说明性示例；超出原文的实质技术展开先列为建议，不悄悄塞进已审核口播。

## 表现风格候选

| visual_treatment | 适合 | 保持一致与限制 |
|---|---|---|
| 手绘笔记 / sketch-notes | 概念、方法对比、学习路线 | 黑线与少量强调色，真实道具和小插画；小黑/小柠檬沿用自身角色 |
| 课堂白板 / whiteboard | 推导、批注、关系连接 | 信息逐块展开；保留真实对象和关系，不退化成空框 |
| 黑板粉笔 / chalkboard | 判断、分类、知识关系 | 暗底高对比，局部点色；不是把所有字改白色 |
| 水彩情境 / watercolor-scene | 学习/办公情境、过渡 | 低信息密度；适合背景或场景，不承载密集技术文字 |
| 教材信息图 / textbook-infographic | 结构、实例、清单 | 版面网格稳定，准确文字独立排版，插图解释对象 |
| 轻立体科技 / soft-3d | 概念物件、数据与工具隐喻 | 立体对象与二维准确标注组合，不强改IP身份 |

这些是项目style_id之内的局部处理候选，不增加或替换现有风格ID。按用户参考与项目风格选兼容项；例如小黑项目可用笔记、白板、教材排版，不在每镜随机换成完全不同系列。资料截图可保留原貌，外围标题、边框和批注统一。

用户的参考图展示了：三种笔记法的分栏比较、白板批注、专注时段的水彩场景、AI概念分格、链式规则的推导、信息化和Agent知识结构、费曼学习步骤、提示词手册、批量生图流程、黑板分类和Token概念信息图。学习其信息组织与表现关系，不继承品牌、数字、业务主张或画中指令；本文件不依赖原Downloads目录存在。

## 全片搭配与受控变化

1. 先标每段的理解任务，给出候选图型，再选图。长于一个视觉节拍的知识点可用“整图建立对象→局部批注→具体实例”，复用设计但改变有效焦点。
2. 同样适配语义时，优先选近期少用的图型/构图；需要随机选择时先过滤兼容项，再用项目random_seed选取并记录，重试不重抽。不得为随机性改变技术关系。
3. 总览列出每拍的media_role、diagram_type、visual_treatment及I/V/BG引用，检查相邻镜头是否总是同一左右矩形卡。连续相似若有稳定对比或教学需要可保留并解释；不设凑数比例或每片必须出现所有图型。
4. 教学信息优先知识图/实例/屏录，实拍负责情境与节奏。允许素材缺失时以明确标示的自制图示替代，但先更新01及缺项，不能到04随机塞视频。
5. 3—5秒仅为局部事件建议间隔，不强制换镜；按语义保留稳定阅读窗口。较长表格/长图可跨拍，按结构总览、重点字段、具体例子分配视图；同图重新弹入不算新的有效焦点。

## 横屏中的竖版知识图

竖版密集海报可以借鉴设计，但不直接缩成横屏中央小图承担教学。01可以直接设计单张或两张独立竖图，按最终显示尺寸控制信息量，详见[图片画风执行契约](visual-style-contract.md)。对于既有密集海报，决定以下路线之一：重排为横屏知识图；把完整海报拆成若干独立模块；保留长图并规划固定窗口、局部放大与阅读停顿。准确中文、流程、表格优先程序排版；角色、情境、道具用生成图或匹配素材，再与文字组合。不要用“准确中文需要排版”作为取消插画、全部改成空框图的理由。

## 单主题搭配示例

若原文依次讲困惑、定义、组成、方法、实例、错误和检查，可对应：敲键盘情境V→概念I→示例表格与L批注→方法比较I→屏录V或实例I→正误对照I→检查清单I。只采用原文实际包含的环节，不为了凑这一顺序补写内容。敲键盘不能冒充正在执行某项具体测试，操作细节需真实屏录或注明示意。
