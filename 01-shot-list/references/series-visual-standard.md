# 三种风格的稳定系列规划 v1

分镜先执行[关系驱动的剪辑规划](relation-first-storyboarding.md)：通读全文，分析段落与子关系，再决定画面单元、重点文字、图片及关系动效；不可先套情境或固定镜头数。


用户于2026-11-18要求：小黑、小柠檬IP、无人物三种风格均有稳定的构图、主视觉与动效规则。01、02、04读取本文件及[固定系列参数](series-profiles.json)，只加载当前style_id对应的[小黑提示词](series-prompts/xiaohei.md)、[小柠檬提示词](series-prompts/lemoner.md)或[无人物提示词](series-prompts/no-character.md)。

## 优先级与稳定范围

1. 用户本次明确指定的风格、参考及任务配置优先；随后是本系列profile和风格身份；通用画风目录及历史项目示例只在不冲突时使用。
2. 新的xiaohei、lemoner、no-character任务默认分别使用series-xiaohei-v1、series-lemoner-v1、series-no-character-v1。同style_id跨文案保持profile_id/version，不能因为换kb或项目seed而重抽整套画风。
3. 固定材质、配色角色、字体层级、节点外观、信息主次、常规运动幅度与验收尺度。允许随知识变化的是主体隐喻、对象、具体布局、图型、关系、时长和镜头数。不是每镜同构图，也不是给三种角色统一涂同一种水彩。
4. task.style仍只写现有三个ID，不能写profile_id。沿用task指定背景、音色、已审核口播、字幕与人物政策，不因引用kb-255而强制更换背景或复制其表情包。无人物仍M=0。
5. 这是后续默认规划规则，不自动追溯修改旧项目，不启动API、配音、渲染或远端写回。尚无新跨文案生产验证，不能宣称已经自动保证效果一致。

## 主视觉、知识关系与构图

先写“本镜让观众理解的关系”，再设计完整画面。完整主视觉可以是情境插画、具象技术结构、带真实规则的实例或原生表单，不要求每镜都画大型插画。但不能用三个无关小物件＋标题来冒充完整解释。

主视觉复用前必须通过[连续性契约](asset-layer-continuity.md)的**语义合格**门：遮住外挂标签仍能辨认本镜关系；对得上关系表；口播关键实体在画面中可辨认。仅工程合格（文件在、hash对）不够。系列返工时不得把上版无特征图标拼盘整包标成 ready。

默认空间以16:9、1920×1080规划：顶部约y=.05–.14给章节，中部约y=.18–.77给知识，底部约y=.85–.95留原字幕。实际文字边界、整个运动路径均需检查，不能只按中心点判安全。

| 镜型 | 使用条件 | 完整阅读画面 |
|---|---|---|
| 主插画＋关系层 | 观点、抽象方法、误区或能力组成 | 一张有解释力的主插画，加准确节点/连接/结论；可左右，也可上下 |
| 流程推进 | 输入、处理、输出或前置依赖 | 顺序、流向和到达状态同时清楚；先有节点再接通关系 |
| 同维度比较 | 两种做法、结果、代价 | 同行同维度，差异与证据可并看，不只换两个标题 |
| 层级／职责 | 组成、上下游、模块边界 | 层级、归属和跨层关系明确，可用有道具支撑的结构图 |
| 实例／表格／表单 | 参数、边界、证据或状态核对 | 具体条件、准确值、预期/实际及判断可对应 |
| 前后变化／闭环 | 修复、筛选、追踪或回收 | 变化前因、实际操作、结果及闭合关系可核对 |

主插画＋关系层的起点可为左图框[x=.10–.47,y=.19–.77]、右知识区[x=.52–.94,y=.20–.75]；按内容可镜像或换镜型。这是规划起点，不是所有镜头的硬编码。主体应占所分配图框的主要可见面积，通常可先按70–90%检查；该比例针对实际主体包围盒，不是PNG外边框，也不是自动评分。不能把所有知识对象压到角落，为偶尔出现的表情永久空出半屏。

字体层级在同一系列内固定：1080p预览可先取章节56–64px、节点36–44px、批注30–36px，按实际阅读调整；普通字幕继续使用生产配置。这些是预览像素，不能直接写成剪映原生字号。关系节点使用一致的白/暖白填充、深色细描边、小面积语义色标和深色原生文字，不能每个项目重画一套卡片。

每镜明确一个视觉重心，再安排辅助证据。背景、装饰、角色和表情不与知识重心竞争。留白用于分组、阅读和即将发生的动作，不是缺少解释内容的补丁。准确标签靠近所解释对象，线条端点、状态颜色与口播事实一致。

## 三套视觉常量

- **小黑**：黑墨手绘＋白/暖白阅读底＋克制橙蓝批注。保持真实参考的黑色豆形、白眼和细肢；以检查、操作、提问等动作与设备/文档/结构互动。保持完整情境，不自动降级为纯黑白小图标拼盘。
- **小柠檬**：标准IP身份＋粗深棕描边＋亮黄/浅蓝二维扁平色；道具和知识对象采用同系列线条与填色。角色有具体教学任务，复杂结构可不放角色；不改水彩脸、写实3D或换服装。
- **无人物**：kb-255的暖纸感彩色手绘主插画＋准确原生关系层。细描边、克制浅色填充和轻体积，保持完整的知识隐喻。无人物/手/拟人形象，无人物表情包；不能因无人而退化成文字页。

三种风格共享知识层级和动作方法，不互换身份。kb-255只提供已观察到的构图/材质参考，不搬用其知识事实、9镜数量、左右布局次数或表情策略。当前保存的三张kb-255插画及一张小黑情境[素材样本](series-reference-assets/provenance.json)中，kb-255样本来自原生草稿里的真实主插画，小黑样本来自先前沿用的参考；都不是本次新生图。kb-255样本非整帧截图，也非生成提示词原文。

## 动效的稳定语法

每镜按“主体建立 → 知识操作/关系推进 → 状态确认 → 完整结果停稳”规划。常规归位可先取0.35–0.6秒、画布2–5%的短距离；完整结果先预留约2–4秒阅读，内容密集则延长或拆镜。以上是初始建议，按真实配音和可读性调整，不能每镜机械照抄。

解释动作从连接建立、字段传递、逐行比较、扫描核对、筛选、分支、层级组装、闭环回收中按语义选。其路径/速度服从解释任务，不受常规归位短距建议限制。只增加位移关键帧不算解释成立。

停稳后没有新的讲解任务就保持位置/比例。禁止循环抖动、全局呼吸、铅笔统一扫屏、快速缩放回弹、为表情大幅甩出返回、默认横穿画面出场。表情仅在允许风格按语义短时呈现；按当前镜的阅读过程预留位置或暂隐遮挡内容并恢复，不永久缩小全片知识区。无人物不加表情。

## 提示词与素材策略

- 系列提示词只描述本风格稳定常量；逐镜提示词描述本稿隐喻、主视觉、关系、布局、动作与阅读结果；素材提示词落实具体文件及参考。不要让素材级“一个对象一张图”反过来决定所有镜头的构图。
- 完整主插画可以保留整体；其中只有确需分别运动的对象才另备独立素材。主插画内部本来完整的机器、管道、手持关系不为拆层强行切开。不默认从完整图按预设矩形硬切。白底保留，透明仅在01明确需要时处理。
- 角色身份参考与画风参考分别声明。API支持参考编辑时传真实身份/风格样本；不支持时明确记录能力限制，仍检查返回图的身份、材质与系列一致性，不能只写一段描述就声称锁定成功。
- AI图只走用户已配置API。准确中文、数值、连线、节点状态后期原生排版。保留真实提示词、来源与hash，密钥不进入输出。

## 01／02／04如何交接

继续使用现有schema：visual_design.selection_mode=authored_per_asset；visual_style_id采用本风格profile_id；在authored_treatments定义固定medium/palette/reference_policy和本稿semantic_reason。逐图使用同一系列材质，只在diagram_type和内容构图上变化。series_parameters保存profile_id、version、本系列实际参数及参考文件hash；不是只填一个名字。现有validator支持authored_per_asset，不新增虚构selection_mode。

execution_contract.main_video_language写全片的构图、主次和动作语言；character保留本风格真实身份。每场景objects/asset_requirements/action_specs写坐标、时段、初末状态、实际属性和可见结果，reading_window_s按配音校准；Markdown和JSON同步。新增profile元数据不会被既有visual_gate自动评价，执行者须实际比对本文件，不能声称机器已自动锁定审美。

02继承同一profile，不重抽、不重新发明材质；确认实际主体面积、道具完整、身份一致。04用同一计划构建MP4与剪映草稿，回读24fps、坐标轴、层级和原生关键帧；工程边界执行[素材连续性契约](asset-layer-continuity.md)。

## 先静态过关，再动起来

先保存静态分镜联系表或版式预览：是否有完整主视觉、知识关系、清楚主次、足够主体大小和稳定系列材质？若只是小图标排队、大白板空置或只有文字，先改01，不用动画补救。

再做包含复杂知识关系和角色（适用时）的代表样片，与本风格参考并看。分别检查：视觉设计是否完整、动作是否解释内容、阅读是否舒适、剪映是否与MP4一致；并做遮标签语义抽帧。旧的“没有抖动”检查继续保留，但不能替代视觉质量。视觉返工若成片/主素材与上版同 sha 且未证明语义仍合格，不得宣称已按新系列规则完成。完整连续审看、人工审听和应用播放分别记录，未完成不填true。
