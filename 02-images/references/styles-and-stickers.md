# 风格与表情选材

当前三风格的完整视觉以[稳定系列规划](../../01-shot-list/references/series-visual-standard.md)为准；本页角色身份与表情边界继续生效。风格名称不等于整片布局，不能把小黑自动简化成黑白小图标、无人物简化成纯文字卡片。

## 迁移来源与适配边界

资源复制自本项目 `gzh_to_video/03-images`：保留完整 `assets/emotional_image_for_cut` 素材库、意图候选、小柠檬标准图。四套风格的视觉语言提炼后写入本文件及style-profiles.json；没有复制依赖旧总控、02口播、03输出、05剪辑的执行脚本。此skill可独立使用，不需要原目录继续存在。

原流程的固定语速、固定表情占比、单帧最多两张、强制规则打字机、95%素材缩放、整页禁令不适用于本流程。图片尺寸、数量、动效与信息关系以01及用户要求为准。沿用源库的语义选材方法，不继承要求回到原03/05执行的命令。

## 风格选择

| style_id | 适合内容 | 设计方法 |
|---|---|---|
| card-grid | 知识卡片、设备流程、技术结构、资料清单 | 暗十字底纹、白卡、青色重点；清晰黑体，图表优先矢量 |
| apple | 产品结论、对照、少量重点 | 无品牌黑底极简发布会视觉，白字青色强调，克制玻璃物件；apple仅为内部ID，生成指令使用无品牌描述，不加入Logo/商标 |
| xiaohei-illustrated-infographic | 图文并茂知识讲解、章节型视频 | 小黑插画＋准确中文和关系层，橙蓝紫章节色、浅色分组；可叠加已规划语义表情与短音效 |
| xiaohei | 解释隐喻、阻塞、关系、情绪 | 纯白、细黑手绘线、少量红橙蓝批注；小黑是实心黑色不规则小怪物，白点眼、细腿、冷静神态，承担概念动作，非角落装饰 |
| lemoner | 测试人IP、教学动作、轻松解释 | 纯白、粗深线、扁平色、亮黄柠檬角色；参考下述身份锁，动作随内容变化 |
| meme-grid | 误区、质疑、反转、轻松知识讲解 | 暗网格、白色大字、黄色重点、红色风险；表情只表达反应，不代替知识结构 |

结构图、流程图、文档长图仍按01准确呈现；选小黑/小柠檬不意味着每个密集技术图都塞角色。角色适用于指定隐喻/情境图，其他卡片保持该系列线条和色彩。白底素材可作为白卡上屏，无需强行抠掉白色。要求透明时必须真实透明，不能用棋盘背景充当透明。

动态网格背景单独保存运动参数或真实视频路径。已批准静态网格不可擅自替换为不明剪映资源。颜色、字体替代、风格对01的影响均写style-lock和design-report。

## 小柠檬身份锁

使用 `lemoner/ip-canonical.png` 核对，`ip-lock-plate.png`/`ip-canonical-white.png`作为参考编辑图，使用前查看。亮黄略扁宽柠檬头罩，两端各三小点，头顶正中一短褐茎加一绿叶；浅米色脸、粗黑圆眼镜、深棕圆眼带两个白高光、淡粉腮红；短黄四肢，浅蓝背带裤、两深色扣、白胸牌黑字“点工”。保持粗描边二维扁平色。只变姿势、动作、道具和轻微表情，不换水果、去眼镜、换服装、添加草帽或冰袋。不得把角色参考GIF直接当成视频贴纸。

## 表情包选择与保存

1. 台词中存在疑惑、反转、发现异常、恍然、夸奖等反应再选用。使用 `sticker-intents.json` 查intent候选，或运行脚本检索库。不是关键词命中就直接采用，必须查看画面/动图确认态度。
2. 原生贴纸优先使用有语义标注、可验证本机渲染的资源；仅有ID或PNG预览不等于本机可渲染。未验证写`unresolved`，不计入ready。需要离线可靠素材时按项目风格采用匹配的本地GIF/图片，保存provider与选择理由。
3. 未标注原生候选仅用于人工检查扩充，不自动进片。选定本地文件必须在库内真实存在。相同resource_id/内容不重复垫场。
4. 互动表情逐词匹配：台词有“666”才能用666；有“点赞/收藏/关注/转发/三连”才能用对应图。不将点赞当666；源候选中也可能有弱匹配，不能照单全收。cta_666选中名称或文件路径必须含666/六六六。
5. 项目内编号M01、M02…；复制原GIF保留动画，原生资源保存预览及resource_id，不能把PNG预览冒充动态图。JSON记录intent、matched_text、match_reason、provider、source、项目相对路径、格式、尺寸、时长/帧数、镜号、入出点、位置/大小、裁切、动效意图与验证状态。
6. 出场大小根据主体可见边界与01布局决定，不统一缩放95%，不能覆盖字幕、关键节点或箭头。只在情绪短暂停留，不让搞笑素材抢走结论。匹配不足则不选，并记录原因。

检索命令（在任意目录运行，返回候选，不自动选用）：

```bash
python3 <skill>/02-images/scripts/search_stickers.py '疑惑' --limit 8
python3 <skill>/02-images/scripts/search_stickers.py '666' --provider local --limit 5
```

库内历史JSON可能写有原03/05路径，这些只作来源说明；本模块执行以本阶段的workflow.md、交付协议及项目文件为准。

## 当前新任务的支持边界

新任务只允许xiaohei、lemoner、no-character；上表其它ID是历史兼容资料。no-character采用独立中文、卡片、图标、信息图、结构/流程关系与动效，不使用人物、角色、拟人形象或表情包。小黑/小柠檬M目标按00固定seed生成5—10处，语义不足允许少于目标并说明，不随机硬贴。


真人/手部视频是独立的footage_policy维度，按[视频素材规范](../../01-shot-list/references/video-asset-spec.md)执行。默认关闭；仅用户明确开启时允许真人视频，no-character的生成图仍无人物、M仍为0，交付标明混合模式。style-profiles的角色/图标规则继续用于生成图，不自行据其开启真人视频。

跨阶段素材身份、角色参考、样片及最终审看要求统一见[执行质量契约](../../01-shot-list/references/execution-quality-contract.md)。
